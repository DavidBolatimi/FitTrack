# Data Dictionary

All data is synthetic and generated by `src/generate_data.py` (seed = 42). The observation window is 2026-01-05 to 2026-06-28.

## users.csv (one row per user)
| Column | Type | Description |
|---|---|---|
| user_id | int | Primary key |
| signup_ts | timestamp | Account creation time |
| acquisition_channel | text | organic, paid_social, paid_search, referral, app_store |
| device | text | ios, android, web |
| country | text | US, UK, CA, DE, IN, BR |
| age_bucket | text | 18-24, 25-34, 35-44, 45+ |
| experiment_group | text | `control` / `treatment` for the onboarding A/B test (signups in weeks 5–12), otherwise NULL |

## events.csv.gz (one row per event)
| Column | Type | Description |
|---|---|---|
| event_id | int | Primary key |
| user_id | int | FK → users |
| event_name | text | signup, onboarding_complete, workout_completed, feature_used, trial_started, subscription_started, subscription_cancelled |
| event_ts | timestamp | Event time |
| feature | text | For `feature_used` only: workout_plans, nutrition_log, social_challenges |

## subscriptions.csv (one row per paid subscription)
| Column | Type | Description |
|---|---|---|
| subscription_id | int | Primary key |
| user_id | int | FK → users |
| plan | text | monthly ($12.99/mo) or annual ($99.99/yr) |
| start_ts | timestamp | Paid start (trial start + 7 days) |
| end_ts | timestamp | Cancellation time; NULL means still active |
| mrr_usd | float | Monthly recurring revenue contribution |

## Metric definitions
- **Onboarded**: completed the onboarding flow.
- **Activated**: completed at least one workout.
- **Retained in week N**: completed a workout between 7·N and 7·(N+1) days after signup.
- **Paid conversion**: share of signups with a `subscription_started` event.
- **Revenue to date**: MRR × months active within the observation window.
